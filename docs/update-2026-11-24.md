공개된 6개 앱과 웨딩 가든 저장소는 11월 24일 인증 없는 HTTP 요청으로 200 응답과 제목을 확인했다. 원본 앱 소스·데이터·공개 설정은 수정하지 않았다. 실행 주소가 확인되지 않은 4개를 실행 가능한 공개 앱으로 표기하지 않는다. 세 신규 inside 저장소는 실행 빌드만 공개한 저장소이므로 상세 페이지의 링크도 ‘배포 파일’로 표시한다.

새로 캡처한 이미지는 `assets/screenshots/*.webp`, 기존 검증 화면을 원본 그대로 가져온 이미지는 PNG다. 모든 카드에서 기존 공통 16:10·contain 설정으로 전체 이미지를 표시한다.

PC 1440px와 모바일 390px에서 카드 40개·하단 목록 45개, 새 항목 10개 각각의 검색과 상세 페이지, 공개 준비 상태, 이미지 로드·contain·가로 넘침 없음, 기존 목록 전용 작품의 검색과 게임 필터를 확인했다. 페이지 JavaScript 예외는 없었다. 기존 스모크 테스트와 서버 테스트 5개도 통과했다.
